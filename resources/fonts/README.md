# Status card font

`NotoSansSC-status-subset.ttf` is a static 700-weight subset of Noto Sans SC 2.004 containing ASCII, the punctuation used by the status card, and its fixed Chinese labels. It lets the dashboard keep its Chinese UI on minimal Linux installations without requiring a system font package.

Source: `google/fonts` commit `809e4d8b8d7e9364a914909bb777679606c178b8`, file `ofl/notosanssc/NotoSansSC[wght].ttf`.

The subset was generated with fontTools 4.60.0 and is distributed under the SIL Open Font License 1.1 in `NotoSansSC-OFL.txt`.
